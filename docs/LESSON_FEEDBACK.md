# Обратная связь по урокам

## Поведение

- Для нулевого потока обязательный feedback включён по умолчанию. Общий переключатель расположен в `/admin/feedback`; индивидуальное значение урока может наследовать, включать или отключать общее правило.
- Опрос открывается после прохождения всех обязательных блоков. Если урок содержит обычное ДЗ для наставника, опрос ждёт принятия (`approved`). SQL-практика остаётся проверяемой существующими серверными заданиями и не требует ручного принятия.
- День 14 открывает опрос только после успешной сдачи итогового теста. Сертификат не выдаётся, пока не собраны обязательные отзывы.
- После отправки feedback финальный и уникальный для пары ученик/урок. Для повторного прохождения или исправления ответа потребуется отдельная бизнес-логика и миграция.
- При отключённом правиле прежняя логика завершения урока сохраняется.

## Хранение и безопасность

Миграция `20261027174226_lesson_feedback_system.sql` добавляет общий переключатель, настройки и вопросы по урокам, а также таблицу ответов с ограничением уникальности, рейтингом 1–10, уровнем сложности, статусом и временными метками. Включён RLS: ученик может читать только собственные записи, администратор — аналитику. Создание/изменение ответов доступно только проверенным серверным обработчикам с service role; `user_id` всегда извлекается из Supabase Auth access token, а не из параметров клиента. Анонимные права отозваны.

Сервер заново проверяет доступ к уроку, обязательные блоки, результаты интерактивов и принятие домашней работы. Серверное действие завершения урока отказывает, пока нет feedback. Клиентская форма не является границей безопасности.

## Администрирование и аналитика

В `/admin/feedback` можно задать общее и индивидуальное правило, выбрать общий шаблон вопросов или настроить отдельный набор для урока, редактировать вопросы и порядок, выбрать тип ответа и обязательность, настроить варианты выбора. Аналитика содержит число отзывов, среднее/медиану, распределение 1–10, сложность, ответы по уроку, фильтры по ученику, датам, оценке и сложности, сводку курса и CSV-экспорт с применёнными фильтрами. Персональные ответы доступны только администратору.

Настройки вопросов хранятся в БД; начальный шаблон заполняется миграцией и автоматически назначается новым урокам. Для аналитики сохраняются стандартные ID `rating`, `good`, `unclear`, `improve`, `difficulty`, `comment`; для вопроса сложности нужно сохранить стандартные значения `too_easy`, `normal`, `hard`, `too_hard`.
